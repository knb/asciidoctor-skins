== 段落

AsciiDoc では段落に特別なマークアップは不要です。
段落は 1 行以上の連続したテキスト行で定義されます。
段落内の改行は表示されません。

新しい段落を始めるには、少なくとも 1 行の空行を入れます。

 リテラル段落です。
 先頭に 1 文字以上のスペースを入れた連続行で構成します。

 等幅フォントで表示され、空白は保持されます。

Roses are red, +
violets are blue.

[%hardbreaks]
ルビーは赤色です。
Java は黒色です。

[.lead]
このテキストはリード段落（大きめのフォント）としてスタイルされます。

この段落はリード段落としてスタイルされません。

== 置換のエスケープ

In /items/\{id}, the id attribute isn't replaced.

\*Stars* isn't displayed as bold text.

\§ appears as an entity reference.

\=> The backslash prevents the equals sign followed by a greater
than sign from combining to form a double arrow character (=>).

\[[Word]] is not interpreted as an anchor.

+/user/{id}+ のように単一プラスで囲んだ語句は置換されません。

dev++{conf}++ のように語中の属性参照も置換されません。

+++<del>strike this</del>+++ は削除済みとしてマークされます。

pass:[<del>strike this</del>] も削除済みとしてマークされます。
