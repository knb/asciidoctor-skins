= Skin Maker

Skin Maker separates AsciiDoc stylesheets into *layout* (structure) and *theme* (fonts, colors, and spacing tokens).

== Concept

[cols="1,2",options="header"]
|===
| Layer | Role

| `scss/layout/` | Heading bands, TOC placement, tables, and section structure (rarely changed once set)
| `themes/*.yml` | Color, font, and spacing tokens (the main tuning surface)
| `scss/_tokens.scss` | Sass variables → CSS custom properties on `:root`
| `scss/_base.scss` | Import of Asciidoctor default CSS
|===

== Layout presets

[cols="1,2",options="header"]
|===
| ID | Description

| `material` | Filled heading bands and sidebar TOC (material-* family)
| `plain` | Minimal typography-focused layout
| `bootswatch` | Horizontal navbar TOC with document side margins
| `tufte` | Serif typography and wide margins (Tufte-style, no base CSS dependency)
|===

== Setup

[source,bash]
----
bundle install
----

== Visual editor

Tune colors and fonts in the browser and export theme YAML.

*GitHub Pages:* https://knb.github.io/asciidoctor-skins/skin-maker/editor/index.html[Skin Maker editor]

[source,bash]
----
bundle exec rake editor:open
----

`editor:open` generates assets, renders `index2.html` and `index2-ja.html`, starts the HTTP server, and opens the browser.

CAUTION: Opening `skin-maker/editor/index.html` via `file://` (for example `xdg-open skin-maker/editor/index.html`) disables live preview because browsers block `fetch` and iframe access on local files. Color editing and YAML export still work.

The editor also runs on GitHub Pages (project site prefix `/asciidoctor-skins/`). On each push to `main`, CI runs `editor:prepare` to generate preview HTML and source maps before deploy.

Features:

* UI language: English (default) and Japanese
* Layout switching: `material`, `plain`, `bootswatch`, `tufte`
* Live preview on `index2.html` (English) and `index2-ja.html` (Japanese)
* Source inspect: click a preview element to see matching AsciiDoc source
* Download theme YAML
* Download compiled CSS (local server via `editor:open` / `editor:serve` only)
* Copy CSS custom-properties block to the clipboard

WARNING: GitHub Pages cannot run the Sass compile API, so CSS download is unavailable online. Download YAML and build CSS locally with `skins:build`, or run the local server to generate CSS.

Save exported YAML under `themes/`, then compile:

[source,bash]
----
bundle exec ruby skin-maker/bin/skin-maker generate themes/my-skin.yml
bundle exec rake skins:build[my-skin]
----

== CLI usage

=== Create a new skin

[source,bash]
----
bundle exec ruby skin-maker/bin/skin-maker new my-brand --layout bootswatch
# edit themes/my-brand.yml
bundle exec rake skins:rebuild
----

=== Regenerate existing material themes

[source,bash]
----
bundle exec ruby skin-maker/bin/skin-maker themes:material
----

== Rake tasks

[source,bash]
----
bundle exec rake editor:build       # css/editor/*.css + manifest.js
bundle exec rake preview:index2     # generate index2.html
bundle exec rake preview:index2_ja  # generate index2-ja.html
bundle exec rake preview:pages      # both preview pages
bundle exec rake editor:prepare     # editor:build + preview:pages
bundle exec rake editor:serve       # HTTP server (PORT=8765)
bundle exec rake editor:open        # prepare + serve + open browser
bundle exec rake skins:generate     # themes/*.yml → scss/skins/*.scss
bundle exec rake skins:build        # scss/skins/*.scss → css/*.css
bundle exec rake skins:rebuild      # generate + build
----

== Example theme YAML

[source,yaml]
----
name: my-brand
layout: bootswatch
fonts:
  google: none
  body: Helvetica Neue, Helvetica, Arial, sans-serif
  heading: Helvetica Neue, Helvetica, Arial, sans-serif
  mono: monospace
colors:
  main: "#FFFFFF"
  primary: "#317eac"
  sidebar: "#2fa4e7"
  link: "#2fa4e7"
  link_hover: "#157ab5"
  text: "#555555"
spacing:
  body_margin_x: 10%
  body_font_size: 14px
  line_height: 1.42857143
----

== Directory layout

[source]
----
scss/
  layout/             # layout (structure)
  skins/              # skin entry points
themes/
  editor/             # default themes for the editor
  material-blue.yml
skin-maker/
  editor/             # visual editor (HTML/JS)
  bin/skin-maker
css/editor/           # editor preview CSS
----

== Relationship to existing skins

Legacy skins under `css/` (`boot-*`, `adoc-*`, `tufte`, and others) remain unchanged.
Skin Maker output also lands in `css/` and works with the `:stylesheet:` attribute and the switcher.

Possible future work:

* Auto-generate switcher.js manifest
* Server-side YAML → CSS compile API
* Extended tufte layout with sidenote support
