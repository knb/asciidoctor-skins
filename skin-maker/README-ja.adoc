= Skin Maker

Skin Maker は AsciiDoc 用スタイルシートを *レイアウト* と *テーマ（フォント・色）* に分離して管理するツールです。

== コンセプト

[cols="1,2",options="header"]
|===
| レイヤ | 役割

| `scss/layout/` | 見出し帯、TOC 配置、表・セクションの構造（確定後はあまり触らない）
| `themes/*.yml` | 色・フォント・余白トークン（調整の主戦場）
| `scss/_tokens.scss` | Sass 変数 → CSS カスタムプロパティ（`:root`）への変換
| `scss/_base.scss` | Asciidoctor デフォルト CSS の import
|===

== レイアウトプリセット

[cols="1,2",options="header"]
|===
| ID | 説明

| `material` | 見出し帯 + サイドバー TOC（既存 material-* 系）
| `plain` | シンプルなタイポグラフィ中心
| `bootswatch` | 水平ナビバー TOC + ドキュメント左右マージン
| `tufte` | セリフ体 + 広い余白（Tufte 風、ベース CSS 非依存）
|===

== セットアップ

[source,bash]
----
bundle install
----

== ビジュアルエディタ

ブラウザ上で色・フォントを調整し、YAML を書き出せます。

*GitHub Pages:* https://knb.github.io/asciidoctor-skins/skin-maker/editor/index.html[Skin Maker エディタ]

[source,bash]
----
bundle exec rake editor:open
----

`editor:open` はアセット生成、`index2.html` と `index2-ja.html` のレンダリング、HTTP サーバー起動、ブラウザ表示まで行います。

`xdg-open skin-maker/editor/index.html`（`file://`）ではブラウザの CORS 制限によりライブプレビューが動きません。色の編集と YAML 書き出しのみ可能です。

GitHub Pages（プロジェクトサイト `/asciidoctor-skins/`）でも動作します。`main` ブランチへの push 時、CI が `editor:prepare` を実行してプレビュー HTML とソースマップを生成してからデプロイします。

機能:

* UI 言語切り替え（English / 日本語、デフォルト English）
* レイアウト切り替え（material / plain / bootswatch / tufte）
* 色・フォント・余白のライブプレビュー（`index2.html` / `index2-ja.html`）
* プレビュー要素をクリックして AsciiDoc ソースを参照（ソース Inspect）
* テーマ YAML のダウンロード
* 完成 CSS のダウンロード（ローカルサーバー `editor:open` / `editor:serve` 時のみ）
* CSS 変数ブロックのクリップボードコピー

GitHub Pages では Sass コンパイル API が使えないため、CSS ダウンロードは利用できません。YAML をダウンロードし、ローカルで `skins:build` するか、ローカルサーバー経由で CSS を生成してください。

書き出した YAML は `themes/` に保存し、以下で CSS 化します:

[source,bash]
----
bundle exec ruby skin-maker/bin/skin-maker generate themes/my-skin.yml
bundle exec rake skins:build[my-skin]
----

== CLI の使い方

=== 新しいスキンを作る

[source,bash]
----
bundle exec ruby skin-maker/bin/skin-maker new my-brand --layout bootswatch
# themes/my-brand.yml を編集
bundle exec rake skins:rebuild
----

=== 既存 material テーマを一括再生成

[source,bash]
----
bundle exec ruby skin-maker/bin/skin-maker themes:material
----

== Rake タスク

[source,bash]
----
bundle exec rake editor:build       # css/editor/*.css + manifest.js
bundle exec rake preview:index2       # index2.html を生成
bundle exec rake preview:index2_ja    # index2-ja.html を生成
bundle exec rake preview:pages        # 上記 2 つをまとめて生成
bundle exec rake editor:prepare       # editor:build + preview:pages
bundle exec rake editor:serve       # HTTP サーバー（PORT=8765）
bundle exec rake editor:open        # prepare + serve + ブラウザ起動
bundle exec rake skins:generate     # themes/*.yml → scss/skins/*.scss
bundle exec rake skins:build        # scss/skins/*.scss → css/*.css
bundle exec rake skins:rebuild      # generate + build
----

== テーマ YAML の例

[source,yaml]
----
name: my-brand
layout: bootswatch
fonts:
  google: none
  body: Helvetica Neue, Helvetica, Arial, sans-serif
  heading: Helvetica Neue, Helvetica, Arial, sans-serif
  mono: monospace
colors:
  main: "#FFFFFF"
  primary: "#317eac"
  sidebar: "#2fa4e7"
  link: "#2fa4e7"
  link_hover: "#157ab5"
  text: "#555555"
spacing:
  body_margin_x: 10%
  body_font_size: 14px
  line_height: 1.42857143
----

== ディレクトリ構成

[source]
----
scss/
  layout/             # レイアウト（構造）
  skins/              # スキンエントリ
themes/
  editor/             # エディタ用デフォルトテーマ
  material-blue.yml
skin-maker/
  editor/             # ビジュアルエディタ (HTML/JS)
  bin/skin-maker
css/editor/           # エディタプレビュー用 CSS
----

== 既存スキンとの関係

`css/` 直下のレガシースキン（`boot-*`, `adoc-*`, `tufte` など）はそのまま残っています。
Skin Maker で生成した CSS は同じ `css/` に出力され、`:stylesheet:` 属性や switcher から利用できます。

今後の拡張案:

* switcher.js マニフェストの自動生成
* サーバー側 YAML → CSS コンパイル API
* sidenote 対応 tufte レイアウトの拡張
